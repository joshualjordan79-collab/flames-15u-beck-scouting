# Flames 15U - Beck: opponent scouting reports

Weekend opponent scouting reports built from GameChanger box scores and play-by-play text. `index.html` lists the reports newest first; each report is in `reports/YYYY-MM-DD.html`.

Every page is self-contained HTML (inline CSS/SVG, no external assets). Charts enlarge with plain links and work with JavaScript off; a small inline script only adds tap-to-sort on table headers. Player names are shortened to first name + last initial.

Live site: https://joshualjordan79-collab.github.io/flames-15u-beck-scouting/
